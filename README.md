# 游戏激活码售卖平台

这是一个面向用户交易的游戏激活码寄售平台：卖家把游戏激活码托管到平台，买家在平台完成购买，平台负责交易过程中的码库存控制、安全交付和资金结算。

当前版本只搭建最小全栈基础架构，保留四个技术方向：

- 鉴权：访问令牌、刷新会话和权限边界。
- 实时通信：经过鉴权的 WebSocket 连接与事件推送。
- 支付：支付单状态与幂等入口，支付渠道暂用本地替身。
- 系统防护：限流、并发隔离、超时与熔断边界。

完整业务闭环规划为“卖家托管激活码 → 上架售卖 → 买家支付 → 平台交付激活码 → 卖家结算”。当前阶段暂不实现商品、码库存、订单、交付和结算等业务代码。

## 技术栈

- 后端：Go、Gin、MySQL、Redis、Kafka
- 前端：Vue 3、TypeScript、Vite
- 运行环境：Docker Compose

## 目录

```text
backend/   Go 服务与数据库迁移
frontend/  Vue 3 基础界面

docs/      架构说明
```

## 本地启动

```bash
cd deploy
docker compose up --build
```

服务启动后：

- 前端：`http://localhost:8080`
- 后端健康检查：`http://localhost:8081/healthz`

当前阶段只验收基础架构闭环，具体接口以 `docs/architecture.md` 为准。
