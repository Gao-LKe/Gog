# 游戏激活码售卖平台

这是一个同时包含自营、寄售和信息撮合的游戏交易平台，三类业务的责任边界不同：

1. 平台官方采购并销售游戏激活码，负责库存、收款和交付。
2. 用户将游戏激活码托管到平台寄售，平台负责收款、安全交付和卖家结算。
3. 用户发布游戏道具信息，平台只提供展示和交流窗口，不参与收款、担保与交易履约。

当前版本只搭建最小全栈基础架构，保留四个技术方向：

- 鉴权：访问令牌、刷新会话和权限边界。
- 实时通信：经过鉴权的 WebSocket 连接与事件推送。
- 支付：支付单状态与幂等入口，支付渠道暂用本地替身。
- 系统防护：限流、并发隔离、超时与熔断边界。

当前阶段暂不实现商品、码库存、订单、交付、结算和道具信息等业务代码，只为后续业务保留技术边界。

## 技术栈

- 后端：Go、Gin、MySQL、Redis、Kafka
- 前端：Vue 3、TypeScript、Vite
- 运行环境：Docker Compose

## 目录

```text
backend/   Go 服务与数据库迁移
frontend/  Vue 3 基础界面

```

## 本地启动

```bash
cd deploy
docker compose up --build
```

服务启动后：

- 前端：`http://localhost:8080`
- 后端健康检查：`http://localhost:8081/healthz`

当前阶段只验收基础架构闭环，具体接口以 `docs/architecture.md` 为准。
